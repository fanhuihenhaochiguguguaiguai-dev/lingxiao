## 如何分析和选择下一步

1. 固定参考图、角度、灯光和姿态，保存实际渲染基线。角色外观以最初确认的银白发设定为准，技能图只补充动作与特效；不把模糊增强结果当成真实设定。
2. 先找范围广且可验证的上游原因：如错误坐标、共享可变状态、导出遗漏或素材引用不一致。选一个代表部件对照实验，通过后再扩展。
3. 共性技术共享，角色脸型、发型、服装和技能造型分别处理。程序化生成用于可控的重复结构；面部神韵、整体比例和艺术质量仍要逐角度观察。
4. 按真实收益、影响范围、成本及回归风险排序。候选没有可观察改善时，保留原因和结果，回退该候选，不把增加面数、粒子或 Bloom 视作质量提升。
5. 分开进行技术、艺术与历史问题回归：能加载只证明资源可解析，命中事件只证明测试场景的判定，不能替代对战平衡、人物相似度、专业听感或手机实测。

## 失败经历与预防

- **模型能导入但外形仍简陋。** 原因是技术加载检查无法衡量原画神韵。今后必须保留原图与真实 3D 多角度对照，技术、艺术两项分别验收。月璃五官、后发、裙装和鞋靴当前仍未达标。
- **程序化裙片、袖片悬空或交叉。** 旧候选使用独立坐标，未与人体及衣层建立正确连接，候选已撤回。先以实际表面拟合并看侧背面，之后仍需动态碰撞验收；静态贴合不足以证明不穿模。
- **发束侧面悬浮。** 射线未命中时错误采用固定前方坐标；改为保留连续路径，仅命中时贴合。见 `qingli-production-lessons.md` 和最新固定角度渲染。
- **只修改 Shape Key 而导出顶点没有相应变化。** 基础网格与变形坐标需要保持同步，直接比较最终 GLB，而非只检查脚本是否执行。
- **跑步脚部悬空与衣袍穿插。** 旧候选未通过，不作为成熟动画复制；先检查接触目标是否在腿长范围，再检查实际鞋底、重心和衣物。当前轻量接触求解不等于全身 IK 或衣服碰撞已经完成。
- **冰晶生成出现黑色扁片，冲击环反向缩回。** 原因分别是单轴缩至零和将扩张与消散绑定同一包络；改为三轴生长、独立控制扩张及透明度。
- **共享材质和时钟造成多实例串扰。** 只共享不可变几何，材质、动态缓冲、时间、音频、位置、命中独立；回收时不得释放仍被其他实例使用的资源。
- **触摸防重复误吞鼠标输入。** 分别识别真实触摸及后续独立鼠标输入；模拟双指时还需确认释放的是正确指针，见 `verification/moonfall/touch.json`。
- **软件图形任务并发导致截图超时。** 本轮单独运行后端验证通过；并发软件渲染不代表手机帧率或硬件性能。

## V3.1 新经验：活动场景、制作母模和证据有效性

- **文件命名／网格定义不等于实际场景。** 三个正式 LOD 文件都挂接全部三档头发；单看存在 `Hair_Lod1` 或静态统计会漏检。修复活动场景连接后，二进制、骨骼与动画不变，同视角绘制调用 59→53、三角形 91094→60638。今后必须遍历活动场景，断言恰好一个匹配的头发档位；导出显式选择、可见和可渲染过滤。
- **不要把假设写成历史根因。** 隐藏对象残留选择是可疑机制，但当前探针没有复现；已证实的是错误挂接及缺少排他检查。修复针对已证实数据，预防覆盖风险，不虚构原始操作过程。
- **高模只负责制作。** 独立离线 Multires 高模实际烘焙法线／AO，运行保留原笼、UV 和眨眼；导出排除 `offline_only`，检查贴图真正被材质引用。成功烘焙仍不代表脸部神韵通过。
- **前面正常也可能侧面失败。** 新前发 45° 出现宽扁尖块，已拒绝且默认禁用实验；不能据正面一张图批量推广至所有 LOD 或另一人物。
- **截图前重置会清掉要验证的状态。** 闭眼测试曾在 Blink=1 后重置角色，截图无效；改为先重置、再设置，并读取实际网格权重验证。记录测试本身的错误及修正，不能沿用失效证据。
- **资源减少与流畅度分别验证。** 此次实际录像依然缓慢，软件渲染计数下降不能替代安卓帧率实测；未使用的二进制未删除，也不能宣称下载缩小。

## V3.5：闭合曲面与失败发型

- **表面看似立体仍可能没有体积。** 原冰莲是开曲面，端点宽度收零却继续生成四边格，产生退化三角形；霜羽两层使用相同绕序，共享边的面向互相冲突；月系晶体未封底且面朝内。`DoubleSide` 把问题隐藏到能渲染的程度，无法补回厚度和正确受光。先用焊接位置建立边关联，再检查开边／不一致面／退化面／有符号体积。新透镜截面花瓣、霜羽和棱柱晶体在实际 Blender、网页固定对照中采纳有限几何改善；原时序、数量、音频和粒子保持。范围见 [本轮记录](../verification/v35/README.md)。
- **棱面需要独立法线。** 冰晶共享顶点直接光滑会变圆；只在晶体表面分离面法线，花瓣保留连续曲率，不把所有材质都改为扁平着色。不同星晶／冰晶保持各自宽高和肩部轮廓。
- **贴合头皮不能自动得到好发型。** 第一版宽发束像尖片；第二版射线贴合的底层头皮仍有帽状观感，前发仍过于整齐。二者均未推广，默认保留原头发，失败复现仅由 `LING35_GROOM=experimental` 开启。不要因为 BVH 命中、曲面闭合或发束变多就宣称发型通过。
- **局部脸部修整须重新烘焙。** 新候选保留 4514 顶点笼、UV 和现有形变，对局部眼眶、鼻唇及其附属结构协调处理，再用既有高低模管线烘焙。仍未接近原画神韵，不替换正式人物、不向月璃复制。技术验收与艺术验收继续独立。
- **测试时钟不能混用。** QA 快进模拟时间不会快进 AudioContext；尚在播放的声尾不能立刻判作泄漏。分别等待技能逻辑回收与原生音频自然结束，不为满足错误断言去中断声音或改写已合格音频系统。

## 基础战斗：身份、姿态与时间的统一约束

用户本轮明确授权普攻、生命、木桩、1v1 和基础 AI，替代此前等待艺术样板的任务门槛。实现与真实证据在 [战斗报告](../verification/combat/README.md)。艺术未验收状态不变。

- **命中反馈不等于扣血权威。** 原训练事件没有生命。新增独立 `CombatState`，通过实际扫掠／范围与真实技能阶段调用伤害；用回合、攻击 ID、来源／目标代次和 tick 去重，不监听 DOM 事件直接扣血。旧视觉记录保留，六技能用同一来源／目标约定。
- **缓存的角色可能正在动。** 对手若直接从正在施法的缓存场景提取骨骼“休息姿态”，会传播旧动作。加载完成时保存导入节点姿态，克隆骨骼／形变后恢复它；几何／只读材质共享，姿态独立。实际双方骨骼 UUID 不相交，切人后缓存最多两个对手实例。
- **动作收招必须维护世界位置。** 凌渊的突进包含角色子节点偏移。对手完成动作时把实际身体位置写回根节点，再进入走跑；否则会跳回旧施法原点。共享原枪式动作数学与枪尖锚定，不重做另一套技能。
- **重启不只复位四元数。** 完整回合重启同时清理步态计时、run blend、弹簧和动作混合；普通姿态检查仍可只复位骨骼，避免改变既有调试语义。背景／失焦清除按住输入和缓冲普攻，AudioContext 的异步解锁重新检查暂停状态。
- **新音频不能制造旧的全局加载故障。** 十二个普攻变体共用原总线；单个失败不阻断其余变体／扣血，沿原重试入口恢复。真实手机延迟和专业听感没有从这些测试推导。
- **调试寻帧也有依赖顺序。** 先按新时刻求人物姿态／枪尖锚点，再重采样特效，最后读位置；旧顺序使用上一姿态的锚点，造成假的同步误差。已在隐藏 QA 入口修正并分别验证正常时间更新与暂停寻帧，不通过放宽命中条件处理。
- **保留合法失败，不给演示写死命中。** 实时演示脚本在持续追敌中释放固定缚星场，AI 已离开旧场中心而落空，等待命中超时。保留实际帧／记录，改用接近后的普攻记录，不修改伤害范围来伪造成功。
- **测试应验证禁用操作而不是等待它可用。** 胜利后的普攻有 `aria-disabled`，Playwright 普通点击会一直等待；改为检查禁用状态和直接无效输入仍被战斗域拒绝，没有移除死亡输入门禁。


## V3.7：操作、几何与伤害共用事实源

- 现象：冰莲侧缘／龙体覆盖却未命中，装饰性大圆反而可能被当伤害范围。已证实根因：旧判定压缩成一个点、统一圆和不完整时间窗。修复：读取实际渲染截面／矩阵，按组件设置有效窗，伤害与地面提示共用区域数据。证据：`verification/v37/{baseline,ranges,cases}.json`。适用：现有程序化六技能；新技能须先定义哪些部件真的伤害，不能把所有光屑当碰撞体。
- 现象：武器看不到接触仍扣血，上半部实际接触又漏掉。根因：虚拟攻击直线与胸口球均脱离实际几何。修复：枪骨／枪尖连续胶囊＋完整竖直受击胶囊。参数只作 AI/瞄准辅助，不再扩张不可见命中距离。小龙须等装饰不作逐面物理；碰撞近似需明确记录。
- 现象：移动施法后足部偏离。根因：IK 后的骨盆／腿部旋转覆盖其结果。修复：保存当前接触目标，叠加动作后再求解；移动大招保留下肢而不套原地悬浮。证据：`cases.json` 同帧前／后约束残差。残差小不能宣称不存在视觉滑步，仍须看连续画面。
- 输入所有权：一个 pointer ID 对应一个瞄准会话；结束、取消、失焦、死亡、切换、重开均清理。程序化 click 与合成触屏 click 分开去重。验收工具教训：CDP `touchEnd` 的非空 touchPoints 指定**结束的手指**，不是剩余手指；先在轻量页面核实协议，不能为适配错误测试而改坏游戏。
- 重开 UI：领域状态即刻恢复而 aria-disabled 等下一帧刷新，会使冻结时钟回归／快速操作卡住。命令完成时立即同步控件，而不是取消死亡输入门禁。
- 持续结算：每实例、每目标记录实际接触时刻与最小间隔，首击 tick 0。单用全局秒槽可能使晚进入的目标短时间连扣；用实际晚进入测试验证间隔。状态去重仍包含来源、回合和生命代次。
- 回收：只停止所属实例声音，不能 stopAll 误切其他人的并发声音。死亡／切换取消旧攻击与待播队列；自然结束仍保留正常尾音。资源检查区分只读模板、动态缓冲和投影池，按受影响范围复验。
- 证据分层：桌面软件 WebGPU/WebGL2、模拟三指/DPR/安全边距、自然时钟无音轨录像都不是安卓真机、专业试听或最终艺术验收。结果索引 `verification/v37/README.md`。

- 同根兄弟层不能只刷新当前视觉组：缚星阵圆环与晶体是并列子节点，采样前更新整个实例根；组件 ID 包含子部件序号。否则矩阵滞后一帧或多个碰撞体复用历史，会产生偏移与错误扫掠。已用平移根节点和缚星阵 1/3/5/10 次复验，见 `verification/v37/cases.json`、`binding-regression/instances.json`。
