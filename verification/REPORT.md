# 凌渊精修与验收记录

**本轮技术检查通过；人物照片级美术质量未通过。** 照片是目标参考，当前模型仍为制作中的工作稿。

## 本轮问题、处理和验证

- 额前尖块、侧发稀疏、眉毛实心片属于粗几何代替细条的同类问题。先在 LOD0 制作分层发束、侧发和独立眉毛细束，查看正侧面，再按各层预算生成其余 LOD。
- 颈部旧网格叠在新头部颈部内，造成接缝；三个 LOD 均移除匹配的旧颈部，保留新头部及原骨架。
- 每档 GLB 的发束蒙皮权重和骨骼名称、四个既有动作通过自动检查；Blender 中行走时发束顶点随骨骼变化。该检查不能证明动画自然或没有穿模。
- LOD0 / LOD1 / LOD2 分别为 91,782 / 56,601 / 38,737 三角面。与上一版相比细发提高了面数；通过把旧的 28 个分散后发对象合并为带三个材质的网格，相同 Chromium 软件测试中 LOD0 绘制调用从 85 降至 59，结果不代表真机帧率。
- 网页改为读取小型模型统计文件，实际请求检查确认桌面启动只加载 LOD0，模拟手机尺寸只加载 LOD1；测试了 WASD 移动、停止待机、LOD 保持位置、回到中心和模拟触屏摇杆。
- 新模型已在 Blender 实际渲染正面、侧面、背面及面部特写；Chromium 软件设备下 WebGPU 与 WebGL2 均能载入并绘制。截图均来自实际三维渲染。

## 验收结果与下一步

- **PASS，技术**：三档模型导出、骨骼与权重、行走时发束变形、既有动作、网页加载及模拟控制检查。
- **FAIL，美术**：脸部神韵、发束层次、发冠、衣甲、长枪的形态与材质仍明显低于用户提供的照片和设定图；眉毛和头发仍需手工精修，不能声称照片级完成。
- **UNVERIFIED**：真实安卓设备的兼容性、帧率和触控；动作穿模、握枪接触、头发物理碰撞及专业美术验收。
- **待处理**：衣领与铠甲重叠、肩甲形态、服装褶皱、龙纹枪细节和面部表情。继续按 `docs/REFINEMENT_WORKFLOW.md` 先处理代表部件，验证后再复用方法。

证据：`lod-validation.json`、`blend-v3.json`、`controls-v3.json`、`webgpu-v3.json` 和 `dist/inspection/` 中的实际渲染图。
