# 凌渊工作稿验证报告（本轮更新）

**仍未达到用户的国漫照片质量标准，不能作为正式人物交付。**

## 本轮变化

- 以 MakeHuman CC0 人体基础网格与青年男性形变为基础，替换工作稿的旧脸部，添加独立眼球和眉毛，并连接现有头部骨骼。该头部为通用基础的初步调整，并非对参考人物的精雕复刻。
- 接入 MakeHuman 官方 CC0 2048 × 2048 皮肤 Base Color，恢复人体原始 UV 并打包在 Blender 文件内；原身体贴图仍保留。没有完成高低模烘焙。
- 调整头发为深色。原有头发、衣甲、长枪结构仍然粗糙。
- 展示台支持 WASD / 方向键、触屏摇杆控制角色移动，角色朝向跟随方向，镜头跟随；松开移动切回待机，可回到平台中心。原有视角、LOD、灰模和动画选择仍可用。

## 验证结果

- PASS：Blender 4.3.2 重新打开母版；包含 58 根骨骼、四个现有动作和打包的 2048 像素皮肤贴图。
- PASS：三档 GLB 含皮肤、骨骼与动作；真实 Blender 渲染正面、侧面、背面及面部近景。
- PASS：Chromium 软件渲染中 WebGPU 与 WebGL 2 均可载入并绘制新版模型；软件渲染帧率不能作为手机性能指标。
- PASS：Chromium 软件渲染的 WebGL 2 中，键盘移动、停止后待机、LOD 切换后位置保持及回到中心通过；模拟手机尺寸和触摸事件的摇杆可移动角色。模拟测试不等于安卓真机测试。
- UNVERIFIED：安卓真机的触控、性能、内存、WebGPU / WebGL2 兼容性。
