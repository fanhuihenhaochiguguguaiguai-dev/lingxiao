# 本轮技能升级与验证记录

## 实际变更

- 一技能：从实际蒙皮模型的 weaponR 权重顶点计算枪尖位置，在起手和突进时将龙首与枪尖同步，之后平滑过渡至挥击轨迹。0.6、1.0、1.3 秒三个采样点的距离由 1.427、1.383、1.344 个场景单位变为约 0；参见 `spear-sync/`。这不证明手部握持和全部动作已正确。
- 二技能：保留此前的龙身盘旋，晶体改为有切面的立体网格，减少过密的粒子。`crystal/` 为相同时间和镜头的前后截图及数据。龙首、鳞片、锁链和动画仍需艺术精修。
- 大招：在已有星渊龙卷工作稿上增加抬升、举枪和落地过程，切换技能时复位高度，页面名称改为「龙吟·苍穹破」。`ultimate-pose/` 保存前后采样与截图；动作仍是程序化工作稿，尚未达到骨骼动画验收。
- 增加标准、高清、极致画质和七种观察角度。`skill-views/` 包含三个技能各七个视角的真实浏览器截图。这是结构记录，不代表美术验收通过。

## 可复现检查

`npm run build --prefix skill-src` 构建成功。`tools/test_skill03.py` 的最终控制与阶段检查结果见 `final-skill-regression.json`；其它采样工具位于 `tools/test_spear_sync.py`、`test_ultimate_pose.py`、`test_crystal_stage.py`、`test_quality_modes.py` 和 `test_skill_views.py`。这些检查依赖本机浏览器和正在运行的本地静态服务器。

在桌面软件渲染、二技能 3.8 秒采样处，标准/高清/极致分别记录 106790/109990/171571 个三角形、176/176/237 次绘制；对应 FPS 为 1/2/2，只反映该软件渲染环境，不代表手机性能。没有可比的本轮升级前性能基线，因此不能声称性能改善。

三张 1280×853 原图共裁出 339 张 PNG，索引及原始裁切坐标见 `../reference/skillboards/`。裁图经插值放大，不能恢复原图不存在的细节；源图中部分画面重叠或细节过小，仍需人工核对。

## 安卓构建状态

`android-app/build_unsigned.py` 生成未签名的 APK，结构和压缩对齐检查通过；`apksigner` 确认未签名，无法安装。`android-app/verify_package.py` 对 APK 内真实资源进行了桌面软件 WebGPU/WebGL2 加载和六项 HTTP 检查，结果见 `android-build/packaged-runtime.json`。没有连接安卓设备，安装、安卓浏览器兼容性、移动 GPU 画质及性能均未验证。APK 是调用已安装浏览器展示本地资源的角色与技能展示应用，并非完整对局游戏。

## 未完成与限制

人物面部、头发、服装、武器、绑定和专业动画本轮没有达到原画级精修；三个技能的龙首形体、材质、轨迹、动作和表现与参考图仍有明显差距。没有实机视觉验收、实际手机帧时间或内存数据，也没有完成战斗伤害、冷却和完整游戏。未发现旧版签名密钥，尚未对候选 APK 进行签名或设备安装。
