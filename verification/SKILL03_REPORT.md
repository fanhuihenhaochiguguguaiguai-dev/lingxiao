# 星渊龙卷 — 人物平台三维特效工作稿

## 范围与参考

按用户后续更正，改动位于 `sites/lingyuan-character-lab` 的现有人物技能网页，不修改《曜境》对局工程。参考包解压于 `reference/skill03/`；其中说明标注三视图是同一原图裁切的概念展示，不是严格一致的正交建模图。

## 本次实现

- 保留一、二技能，增加第三个独立按钮和 7.4 秒演示时间轴：星辰汇聚、龙魂显现、星环盘旋、核心压缩、冲击及余波消散。使用原角色骨架的程序化施法姿态。
- 可旋转的同一套实时 3D 几何包含程序化龙身、独立龙首、角、眼、须、鬃、牙与实例鳞片；三层旋转的金属星环及几何符号、螺旋流光、地面法阵、碎石、星尘、扩散环。龙身使用 Three.js TSL 流动节点材质。没有将原画贴到场景中冒充模型。
- 两档画质调整流光、实例数及画面开销。支持原有暂停、慢放、逐帧、循环、时间轴、自由旋转缩放、正侧背俯视及横屏提示。
- 提供 `lingyuan:skill-cue` DOM 事件，可供未来音频系统监听 `awaken`、`dragon`、`collapse`、`burst`、`afterglow`。尚未制作或接入实际音效。

## 验证

- `npm run build --prefix skill-src`：TypeScript 编译与打包通过。
- `tools/test_skill03.py`：Chromium 软件 WebGL2 验证六阶段、龙头位置变化、三个技能切换、暂停、慢放、逐帧、循环和结束隐藏；各角度截图来自真实浏览器。截图见 `skill03-front.png`、`skill03-side.png`、`skill03-top.png`、`skill03-landscape.png` 和阶段截图。详细结果在 `skill03-controls.json`。
- `tools/test_skill03_backends.py`：软件 WebGPU、强制 WebGPU Bloom、强制 WebGL2 Bloom 和无 WebGPU 的自动回退通过，记录在 `skill03-backends.json`。
- `tools/test_skill03_cues.py`：监听实际 DOM 事件并检验觉醒和爆发事件，记录在 `skill03-cues.json`。
- 软件模拟运行测得约 1–3 FPS；示例 WebGL2 主阶段约 137 次绘制调用，爆发阶段约 140 次。软件渲染测试不代表实际手机性能。

## 未完成和限制

- **视觉质量未通过原画标准**：龙首与鳞片仍简化，龙身整体偏管状，星环符号为程序化几何而非原画铭文；龙鬃、引力扭曲、能量层次、爆发、碎片拖尾和精致程度需要进一步制作与美术验收。
- 角色、衣发、长枪及姿态仍为既有未完成工作稿；握持和穿模没有通过质量验收。动画是演示用程序化骨骼偏移，非完成的专业动作。
- 此页面是人物技能展示平台，没有对局中的敌人、伤害、冷却、正式技能数值或范围判定；因此这些部分没有实现或验证。7.4 秒是展示时间，不代表正式游戏平衡。
- 没有真实手机 WebGPU/WebGL2、触控、帧率、内存、发热或长时间稳定性验收；软件后端的结果不能代替真机。Bloom 在软件渲染默认关闭，未做硬件观感验收。
