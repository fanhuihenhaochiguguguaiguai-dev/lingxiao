# 凌渊第一技能 · 工作稿验证记录

**状态：可运行的单技能三维工作稿；人物与特效的最终美术验收尚未通过。**

## 已实现

- 在现有人物工程内增加 `/skill/` 测试页；TypeScript 严格检查、Three.js 0.180.0，优先 WebGPU、兼容 WebGL2。原人物工程与原检查页保留。
- 使用现有角色 LOD1 和 58 骨骼，包括 `weapon.R`。Three.js 导入时骨骼名中的点被移除，技能控制已映射导入后的名称。
- 一条约 4.4 秒的技能时间线：起手蓄力、前冲、环形挥击与消散。程序驱动角色位移、躯干、双臂、腿部及头发/衣袍骨骼。
- 场景中有真实三维龙首、龙身、角、眼、须、鳞状碎片、环形轨迹及粒子实例，龙身使用随时间变化的 Three.js 节点着色；未使用参考图或视频作为特效平面。只有一名角色和中性平台。
- 相机可旋转、缩放、切换正面/侧面/背面/俯视；支持释放、暂停、慢动作、逐帧、时间轴、循环和两档画质。页面提示横屏；设备允许时可由用户点击请求全屏与横屏锁定。
- 高清与极致档控制粒子数量、渲染分辨率及阴影；支持 Three.js 的 Bloom 后处理。在检测到软件图形设备时默认关闭 Bloom 以降低负载，测试可用 `?bloom=1` 强制开启。采用 ACES 色调映射，不含经验证的 HDRI 环境贴图。

## 验证与限制

- 技术检查：TypeScript 构建成功；Chromium 软件设备中 WebGL2 与 WebGPU 实际绘制，两种后端强制 Bloom 测试通过，不支持 WebGPU 时自动切换 WebGL2 也通过；四个时间节点的龙魂、角色位置与骨骼旋转发生变化。见 `verification/skill-*.png` 和测试记录。
- 横屏布局及触屏页面在浏览器模拟中打开；真实安卓手机的帧率、GPU 和锁屏能力未验证。
- 角色、衣甲及长枪是此前未达到验收要求的工作稿；手与长枪接触、穿模和权重尚未通过验证。
- 当前龙首、鳞片、须及水流为程序化简化三维几何，与参考图的精细神龙和复杂水流差距明显；人物残影、精修龙鳞、专业动画、HDRI、碰撞及最终视觉品质尚未完成。
- 可运行和时间线通过不等于图片级美术验收通过。尚需围绕正式角色和长枪完成专业骨骼动画、龙首雕刻、流体层次、透明排序和真实设备性能验收。
