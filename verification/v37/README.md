# V3.7 战斗操作与真实伤害区域

基线 `499215e059b97718f083c1b7f275e00d068bf97b`；沿用原网站、两个人物、六技能、模型、音频与渲染后端。此轮是战斗机制修复，**没有认定人物、技能整体美术或安卓真机性能通过**。

## 交付与操作

- 左下摇杆、右下普攻，三个技能沿弧形排列；大招独立加大，跳跃移至弧线左侧，人物／设置保留顶部。适配 CSS 像素和安全区，渲染 DPR 不改变触控坐标。
- 技能轻点在松手时释放；按住拖动瞄准，松手释放；移入取消区、拖远或按 Escape 取消。不同手指分别拥有摇杆和各技能，不互相抢输入。技能没有新增冷却或施法队列，1/3/5/10 次轻点各自生成独立实例。
- 普攻仍按 J／普攻键，按住连续；显示实际恢复进度，恢复末段支持短输入缓冲。技能释放后在各自允许的恢复阶段接普攻，原技能实例继续存在。
- 有效地面领域使用轻微填色与边界：敌方红色，己方金／冰蓝；来自**同一份碰撞区域数据**。预警与装饰光效不填成伤害领域；移动龙身、霜羽、寒潮波前依照实体形状。瞄准预览没有伤害。
- 死亡、切人物、重开会清理所属旧攻击与待播声音；其他存活实例的状态、资源不被误清理。设置仍只有声音、画质。

## 已证实的根因与修复

| 问题 | 根因／实际修复 |
| --- | --- |
| 冰莲侧缘覆盖木桩却无伤 | 原技能只检测移动月轮的一个点，忽略冰羽和末端冰莲。旧网页实测位置 `(4.1,0.6,1)` 无命中；现在分别检测三部分，冰莲命中 115。见 [旧记录](baseline.json)、[新事件](ranges.json)。 |
| 龙体／后半段法阵／聚集龙卷漏伤 | 旧判定只采龙首或过短的单一时间窗。现在从实际动态龙体截面、渲染节点与实例矩阵提取胶囊／柱体／环体，独立设置有效阶段。六技能各自保留形态和伤害规则。 |
| 高速跨越、圈外误伤、跳跃高度不区分 | 增加相对运动连续检测与有效时间裁剪；完整竖直受击胶囊代替胸口球；真正环形波前保留中间空洞。目标高于区域不会按无限高的平面扣血。 |
| 平移后晶体判定位置不对／区域编号重复 | 只更新了法阵层，没有刷新兄弟晶体层的世界矩阵；子晶体还曾共用区域 ID。现统一刷新实例根节点并为各晶体分配独立稳定编号，排除装饰金环。平移根节点检查与 [缚星阵连发复验](binding-regression/instances.json) 通过。 |
| 枪尖未触及却可以远距离扣血 | 原普攻是固定 2.7 米的虚拟直线。现对齐实际枪骨／枪尖，检测移动枪身胶囊；AI 距离参数同步收紧，2.8 米外测试无伤，没有放大看不见的攻击范围补偿。 |
| 走动施法后脚位被改坏 | 腿部 IK 先计算，之后施法／过渡又旋转骨盆、覆盖腿骨。现保留走跑下肢，在动作叠加后复算接触；移动大招不再套用原地悬浮与腿姿。 |
| 手指抢输入、无法取消 | 原触屏在 pointerdown 立即施法。改为独立 pointer ID 的瞄准会话，pointerup 只释放一次，取消／失焦／切换清理会话，合成 click 不重复施法。 |
| 重开后按钮短暂仍被禁用 | UI 仅依赖下一渲染帧刷新。重开、模式和人物切换现在立即同步禁用状态；冻结时钟回归也能立即再次操作。 |
| 持续伤害进入时机改变导致短间隔风险 | 按每个实例与目标的实际接触时刻限制最小间隔，首击 tick 为 0，不借全局秒槽提前重复扣血。晚进入领域的实际测试保留在 [lifecycle.json](lifecycle.json)。 |

## 六技能结算边界

| 技能 | 有效组成／时间（本实例秒） | 伤害 |
| --- | --- | --- |
| 凌渊一 | 龙头与实际龙体段，0.95–3.65 | 同目标一次 135 |
| 凌渊二 | 盘龙与法阵内域，1–5.45；生长晶体 2.25–5.45 | 同目标一次 95 |
| 凌渊三 | 龙体 1.1–5.85；龙卷核心 1.7–4.85；冲击爆发 4.85–5.85 | 各部分共用一次 260 |
| 月璃一 | 飞行月轮 0.85–2.15；实体霜羽 0.85–2.8；冰莲 2.12–3.3 | 各部分共用一次 115 |
| 月璃二 | 实际法阵／冰晶 1.45–7，独立环形寒潮波前 | 每目标最小间隔 1 秒，55，减速 0.55 |
| 月璃三 | 冰龙 1.65–9.4；领域／冰晶 3.8–9.4；各冲击环独立有效窗 | 每目标最小间隔 1 秒，100，减速 0.55 |

碰撞是游戏用胶囊、有限高度柱体和环体近似，**不是逐三角形像素级碰撞**。龙须、光屑、外侧装饰星轨等没有被无条件扩大成伤害范围。伤害数值沿用原样板；有效部分／时间补齐后，不等同于竞技平衡已验收。

## 开销与限制

[固定场景数据](rendering/rendering.json)：旧／新训练场同视角均 **78 Draw Calls、73526 三角形**。双人物软件 WebGL2／WebGPU 均 **174／224478**。四轮模式切换几何 **184**、纹理 **16** 稳定；额外两个领域投影几何常驻复用，不代表总堆内存或长期无泄漏。

[十领域对比](stress.json)：旧／新分别 **960／962 Draw Calls**、**672702／674622 三角形**。十个实例完整保留，实际领域投影合并成两个绘制调用，增加 1920 三角形，结束后活动实例归零、同类池最多两个。同一桌面推进 0.25 游戏秒的合成 CPU 开销约 97.7→118.9 ms；包含多步更新，不能当作单帧时间或转换为手机 FPS。

**真机未验证**：安卓触控、真实安全区、帧率／帧时间、GPU 时间、物理音频延迟、温升和长时间稳定性。没有承诺 60/30 FPS。人物／衣发、最终攻击／死亡动画及全部特效的完整艺术品质仍未验收；没有因此修改合格模型。
