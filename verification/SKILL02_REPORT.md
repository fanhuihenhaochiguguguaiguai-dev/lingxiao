# 凌渊二技能：青龙·缚星阵 — 工作稿验收记录

## 实际完成

- 复用同一角色 GLB、已有骨骼和一技能测试工程。二技能有独立按钮及 6.4 秒时间线，覆盖聚灵、阵法展开、龙魂盘旋、晶体／光柱／锁链禁锢、消散与恢复。重复释放会重置时间线；一、二技能切换时各自特效会关闭。
- 法阵线条、龙头和龙身、晶体、锁链、光柱、碎石和粒子为实时几何；不是参考图或视频。法阵按材质合并静态几何，碎片与链环使用实例化；不同画质调整实例数。
- 提供暂停、慢放、逐帧、循环、时间轴、正侧背和俯视、自由旋转缩放；青龙、法阵、晶体、光柱、锁链、粒子有独立显隐。修正了二技能固定正面视角，以及将累计渲染次数误显示成绘制调用的问题，现显示每帧 drawCalls。
- 参考图与文字存在差异：图 03 的瞬移与文字强调的法阵控制、避免重复高速突进不同；本版以原地法阵控制为准，没有实现瞬移。没有添加敌人或第三技能。

## 实测证据

- `npm run build --prefix skill-src`：TypeScript 严格检查和打包通过。
- `tools/test_skill02.py`：本地 Chromium 软件 WebGL2 检查载入、角色及长枪骨骼、两技能切换与特效互斥、六种图层显隐、暂停、逐帧、慢放、循环、四个视角及模拟手机横屏。实际页面截图见 `skill02-front.png`、`skill02-side.png`、`skill02-back.png`、`skill02-top.png`、`skill02-dragon.png`、`skill02-detail.png`、`skill02-landscape.png`；结果见 `skill02-controls.json`。
- `tools/test_skill02_backends.py`：软件 WebGPU、强制 WebGPU Bloom、强制 WebGL2 Bloom、关闭 navigator.gpu 后自动回退 WebGL2 均加载并渲染二技能且无页面错误。结果见 `skill02-backends.json`。这不是实际手机或硬件 GPU 测试。测试脚本依赖 Playwright、Chromium 和 Linux 临时显示环境；本地服务须先从 `dist` 启动在 8765 端口。
- 本次软件渲染测得约 1–3 FPS；示例测试帧显示约 175 个绘制调用，Bloom 测试约 187 个。软件模拟环境与真实设备不可直接比较，需在目标手机上测帧率、内存及发热并进一步合批优化。

## 未完成或未验证

- **高品质画面验收未通过。** 角色仍为此前工作稿，脸部、手部、服饰和长枪不符合原画；本次没有重制角色 PBR 贴图、金属粗糙度、丝绸锦缎、皮肤或宝石材质。
- 青龙为程序化简化网格，龙首、龙鳞、流体、水花及视觉层次明显低于参考；晶体和锁链为简化形体，枪锋细节和高质量地面纹理未完成。星形符文是程序化结构，非逐图精细还原。
- 人物动作是现有骨骼的程序化姿态，没有制作专业关键帧动作；握枪接触、肩甲、衣袍、长发和饰品的碰撞与动态自然度未通过验证。粒子消散表现是简化渐隐，并非完整龙身碎裂模拟。
- 安卓真机横屏、触控、不同 GPU 兼容性、帧率、内存和连续运行均未验证；尚无实际 MOBA 游戏镜头移动场景验证，也没有实机 45 度游戏距离的质量验收。固定视角和模拟横屏不能代替真机验收。
- 软件渲染默认关闭 Bloom，测试查询参数可强制启用；硬件设备的 Bloom 和透明排序仍需验证。
