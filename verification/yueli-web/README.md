# 月璃网页工作稿验证

网页使用 `dist/yueli-study.glb`，与 `characters/qingli/Qingli_static_study.glb` 同源。月璃仍是尚未通过美术验收的静态工作稿：没有骨骼、蒙皮、动作或表情；摇杆改变模型位置，并不代表行走或跑步动画。

网页中的「霜羽」是月华霜羽的实时三维特效试作，并非正式完成的技能：它没有角色施法动画、技能音效、目标检测或伤害。独立时间轴与多角度运行截图见 `../moon-frost/`。素材及原始索引位于 `../../reference/yuehua-shuangyu/`。

`result.json` 与截图来自桌面 Chromium 软件 WebGL2；`landscape-simulated.png` 是横屏触摸模拟，不是真机。`default-renderer.json` 是桌面软件 WebGPU 下的加载和特效可见性检查，不代表硬件 WebGPU、艺术验收或手机性能达标。原 Blender/GLB 衣层几何记录见 `../qingli/REPORT.md`。
