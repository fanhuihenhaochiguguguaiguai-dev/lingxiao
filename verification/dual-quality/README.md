# 双人物增量修复记录

## 已验证的共同根因与修复

- 原位移与动画分别计时、加速仍使用 walk 片段：共享 `CharacterMotion` 改为由实际速度驱动的两套程序化步态；跑步采用独立支撑比例、摆腿高度和屈臂参数。两腿目标根据各自骨架长度求解。该方案没有使用旧的悬空跑步候选。
- 月璃原本无骨骼：保留旧网格、UV、材质及衣层厚度，增量绑定 36 骨骼。凌渊新增两个眼球枢轴后为 60 骨骼。两个角色新增 Blink 几何形变及睫线；共享不等间隔眨眼和小幅眼球探索控制。
- 缓存角色会保留程序修改后的骨骼姿态：切换前恢复原骨骼变换和眨眼权重，避免再次加载时把动作姿态当作绑定基准。连续四次切换已检查。
- 重复输入会直接重置技能：改为单槽输入缓冲，当前技能结束后消费最后一次有效输入；移动、跳跃和施法分别运行。音频调度改为短窗口，避免一次性把整段声音提前排满。
- 原场景仅直接光、扩大场景后阴影不跟随：加入共享环境反射，硬件路径启用跟随角色的局部阴影。软件验证未开启实时阴影，不能据此确认硬件阴影效果。

## 真实新增内容

月璃增加连续内裙，封闭旧独立裙片之间的空隙；局部调整前发曲面与上睫线。凌渊增加上睫线与眼睑闭合结构。固定灯光前后对照为 `face-comparison.png` 和 before/after 原始 PNG；脸型和五官整体几乎未改变，**不能宣称恢复原画神韵**。

月华霜羽把普通环／八面体试作调整为有厚度的月牙、弯曲霜羽与曲面冰莲；使用已有 CC0 录音做独立六层时间安排、静音及音量控制。晶体目标支持扫掠相交、一次施法每目标只记录一次命中并闪光。它是展示用命中接口，未引入未经设计的伤害数值、生命值或冷却平衡。

活动半径从 9.5 增至 `9.5 × √5 ≈ 21.2426`，实际圆形活动面积为原来的五倍；平台外缘另留技能余量，边界限制保留切向运动。设置仅声音、画质，人物选择移到顶部；旧单人物检查页保存在 `model-inspector.html`，首页进入统一工作室。

## 技术验收与实际范围

- `assets.json`：GLB 可解析、绑定权重归一化、骨架及 Blink 存在。不是完整拓扑或美术合格证明。
- `result.json` 与网页截图：两个人物的独立程序步态、接触目标求解、起跳落地、缓冲再次施法、各角度及闭眼。足部误差是**骨骼目标误差**，不证明鞋底、布料碰撞或全程无滑步。
- `interaction.json`：横屏模拟双指移动施法、三个龙技能、月璃命中与音频事件、五倍活动边界、缓存切换。模拟测试修正了 CDP touchEnd 的手指列表，防止把释放摇杆手指误当成释放技能手指。
- `audio-mix.json`：四组声音在 48 kHz OfflineAudioContext 下峰值低于满幅，未检测到削波；不是专业试听或实际扬声器延迟测量。QA 快进的音频事件仅证明调度路径，不能用来测量音画延迟。
- `../yueli-web/default-renderer.json`：桌面软件 WebGPU 的模型与技能加载。其余网页图来自软件 WebGL2。全部没有真实手机、硬件 GPU 的性能结论。
- `resource-sizes.json`：仅记录导出体积变化。没有一致条件的前后帧时间、内存或 GPU 性能对比，因此不宣称性能提升。

## 尚未通过

两个角色与原画的脸型、五官、发型、衣甲、鞋靴和装饰仍有明显差距。闭眼细节、动作重量感、跑步全周期及布料视觉尚未通过艺术验收。现有次级运动只是有界阻尼骨骼，**没有完整衣发碰撞或 XPBD**；仅双腿 IK，未实现全身 IK。基础情绪表情、专属皮肤／眼球贴图、UDIM、纠正形变、精细龙身、专业技能试听和真实设备验收仍未完成。
