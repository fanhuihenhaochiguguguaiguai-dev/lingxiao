# 月影寒潮与即时多实例：真实制作记录

## 工程成果

在同一个工作室加入第二技能「月影寒潮」。三层悬空金色花饰／符文轨道、三个月牙实体、多段生长冰晶、曲面扩散潮、冰莲、霜雾体与月影分身来自真实几何和程序更新，没有把设定图作为效果贴片。分身由现有月璃模型离线烘焙并简化，来源及统计见 `echo-source.json`；源人物本身尚未通过艺术验收。

角色动作控制器为寒潮加入左手凝月姿势，霜羽保留右手释放身份，约 1.8 秒后混回移动；效果继续独立运行。人物、模型和旧技能资源保留，没有新增第二人物大招。

## 根因与共享修复

旧逻辑只持有一组时间、特效、声音与命中集合，因此重复输入只能等待或覆盖。新增 `SkillInstances` 为每次输入立即分配单调 ID、出生位置／方向、时钟、声音变体、事件集合和命中集合。凌渊三技能、月璃两个技能共用此调度器，测试模式没有冷却或排队，没有实际实例数量上限。旧龙的可变材质、流动时钟已改为实例独立，防止多条龙互相覆盖透明度和能量相位。

出生后的特效根节点位于场景坐标，不再跟着角色的最新施法节点搬动。新施法可更新人物当前姿势，但不会重置旧实例。每种效果最多保留 2 个空闲对象用于复用；超出部分在自然消散后释放几何、材质和实例缓冲。不可变寒潮几何和分身网格共用；静态饰件按材质合并，降低绘制调用。并发时降低辅助粒子密度与透明叠加，36 组冰晶、3 个分身及主体月轮仍保留在每个寒潮实例内。

触屏在 pointerdown 触发；只过滤触屏产生的兼容 click，避免“触屏后短时间内真实鼠标点击也被吞掉”。键盘、鼠标和触屏均走相同实例入口。

## 命中与声音

寒潮范围扩张到半径 3.15，领域期按每实例／每目标约 1 秒触发持续命中，减速因子 0.55，状态过期会恢复。训练晶体的移动实际消费该减速因子。命中集合相互独立，同一实例不会在同一 tick 重复记录。当前展示目标没有生命值或正式伤害／平衡参数，提供命中事件与减速接口，不宣称完整对战伤害系统已经存在。

`tools/design_lunar_audio.py` 从噪声、非整数共振、颗粒冰裂和立体反射生成原创声音，没有复制商业游戏音频。霜羽偏明亮锐利，寒潮偏低频、空灵与领域涌动。两个技能各 7 类声音、每类 3 个轮换变体，共 42 个 Web Ogg；`audio-production/lunar/` 保存 14 份 48 kHz 双声道 float WAV 母版及可复现生成器。每次释放有独立声音事件、小幅音高／增益差异和空间位置。

声音由实例阶段及真实命中事件触发。持续领域包含延续氛围和消散尾音。共享声音资源、按并发组归一化、压缩和软限幅；不会为了降低声音负载而丢弃视觉／命中实例。角色切换不会取消场景中已存在的实例。冷启动音频尚未解码时会等待解码并显示加载状态，首次解锁及实际扬声器延迟仍需真机验证。

## 验证证据

- `instances.json`：五个技能分别对 1、3、5、10 次合成 DOM 输入验证准确数量、唯一 ID／根节点、年龄从零开始、独立施法声音事件；移动加跳跃继续创建第 11 个实例，旧实例的时钟与出生坐标不重置；自然结束、池复用通过。
- `touch.json`：Chromium CDP 模拟横屏双指操作，3、5、10 次触碰分别生成同样数量的寒潮及声音事件，摇杆继续有效；另检查触屏后紧接鼠标点击不会漏发。它不是手机实测。
- `visual-runtime.json`、phase 和多角度 PNG：实际软件 WebGL2 下的阶段、几何层次、持续命中、减速、十实例独立命中和回收。十组在 2.8 秒时各有独立命中记录，所有视觉实例结束后活动数为零，声音尾音结束后语音源与待处理事件归零。
- `backends.json`：同一 1100×700 镜头、同一画质、十组效果的 2.8 秒时刻，比较合并与未合并绘制；软件 WebGPU 单组也成功渲染。绘制调用数减少不是手机帧率提升证明。软件渲染约百万三角形的十连发仍有明显压力，不能宣称手机性能达标。
- `audio.json`：42 个音源非空且校验值不同，两种施法音的频谱中心不同。48 kHz OfflineAudioContext 分别混合两个技能及十连寒潮，记录峰值／RMS，未发现满幅削波。试听文件在 `audio-preview/`。这不是专业听感、真机输出峰值或物理音画延迟验收。

## 尚未验收

当前是正式接入网站的制作中效果，**电影级美术品质和专业音效听感尚未通过**。与参考图相比，月影人物细节、复杂纹饰、冰晶折射、体积霜雾、真实空间扭曲及施法动作仍有差距；半透明材质采用实时近似，尚未实现屏幕空间折射、物理体积散射或空间扭曲。第二人物的脸型、服装与自然动作也仍沿用未完成工作稿，没有因特效可运行就视为合格。

没有安卓真机、硬件 GPU 长时间压力、真实触控到画面／音频延迟、实际内存峰值或专业扬声器试听结果。未制作第二人物第三技能，未打包 APK。源码保存于原 Sites 对应版本库，不写入无关 GitHub 仓库。
