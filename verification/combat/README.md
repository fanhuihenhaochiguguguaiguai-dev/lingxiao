# 基础战斗闭环与本地 1v1

基线 `5324e33caceb20be29e587ef9d68fc84d339b68c`。继续原 Three.js / TypeScript 网站、场景、角色资源、六技能、摇杆、跳跃、画质、声音和跟拍。用户本轮已授权基础战斗，替代此前等待美术样板再开展战斗的约定。**人物与技能原画级艺术状态没有因此变成通过。**

## 实际可用功能

| 阶段 | 实现与实际网页验证 |
| --- | --- |
| P0 普攻 | 凌渊突刺／扫击上半身动作、月璃交替手冰羽投射；独立前摇、有效段、后摇／间隔。按 J 或右侧普攻键，按住连续攻击。移动与下半身原控制继续运行。 |
| P1 生命／伤害 | 真实位置判定后扣血、受击姿态／血条／数值反馈、零血死亡、禁止死后行动与结算、重新开始。未命中不扣血，没有用按钮点击直接扣血。 |
| P2 训练木桩 | 3000 耐久，可被两种普攻和六技能命中；受击发亮／摇动，击毁出现八块三维碎片，重置恢复。其余两个原晶体反馈点继续保留并使用同一生命机制。 |
| P3 本地 1v1 | “进入 1v1”让另一位角色以独立骨骼同场出现。双方普攻、六技能命中、血量、胜负、死亡／重新开始通过。切换人物会交换对手并开始新回合。 |
| P4 基础 AI | 追踪玩家、距离判断、近战接近／远程保持距离、普攻、按自身时序使用三技能、死亡停手。没有加入联网或复杂寻路。 |

训练模式下可靠近木桩攻击；1v1 使用同一套操作。设置依旧只有声音、画质，人物按钮仍在原处。纯净模式也会隐藏新增战斗 HUD。原技能继续支持即时多实例和移动／适用跳跃施法；玩家技能未增加冷却，AI 自己采用 6／8／12 秒的技能决策间隔。

## 代码与复用边界

- [`combat-state.ts`](../../skill-src/src/combat-state.ts)：生命、队伍、回合、出生代次、伤害令牌、去重、减速贡献、死亡／胜负。伤害键包含攻击、来源、来源代次、目标代次、伤害 tick；旧回合／旧人物／过期令牌拒绝。令牌 20 秒到期，去重项 30 秒清理，不会因清理去重记录允许旧攻击重放。
- [`basic-attacks.ts`](../../skill-src/src/basic-attacks.ts)：独立攻击姿态、间隔、释放事件、扫掠／飞行命中、池复用。月璃从实际手部骨骼释放，并在释放时确定三维飞行方向；发射后不会追着目标自动命中。角色切换清理该来源的旧普攻状态。
- [`combat-actions.ts`](../../skill-src/src/combat-actions.ts)：各角色独立的上半身普攻、恢复混合、受击／死亡姿态。动作是程序化骨骼样板，**不冒充已经完成专业手工攻击／死亡动画**。
- [`spear-actions.ts`](../../skill-src/src/spear-actions.ts)：提取原凌渊三技能动作数学，供玩家和对手复用，保留原动作／武器绑定。枪尖同步在正常更新路径定向复验。
- [`skill-instances.ts`](../../skill-src/src/skill-instances.ts)、[`skill-registry.ts`](../../skill-src/src/skill-registry.ts)：原实例增加来源及独立战斗命中记录，并配置伤害；训练视觉事件与正式本地扣血分开，DOM 命中事件不是伤害权威。六个原特效源码／模型保持不变。
- [`characters.ts`](../../skill-src/src/characters.ts)：加载时保存导入姿态；对手使用 `SkeletonUtils.clone` 后恢复导入姿态，骨骼／形变独立，几何和只读材质安全共享。不会把正在施法的缓存人物姿态当成新角色的初始姿态。
- [`combat-opponent.ts`](../../skill-src/src/combat-opponent.ts)：基础 AI、独立动作、原技能调用和最多两个角色实例缓存。突进结束将实际身体位移写回根节点，避免收招跳回；对手使用原枪尖锚定方法。
- [`combat-view.ts`](../../skill-src/src/combat-view.ts)、[`main.ts`](../../skill-src/src/main.ts)：木桩、受击／碎片、投影血条、操作、镜头和圆形身体碰撞。新增模式／重置入口使用原界面样式，没有另做大厅或地图。
- [`instance-audio.ts`](../../skill-src/src/instance-audio.ts)：十二个普攻声音变体使用原音频总线、混音、空间衰减、慢速／暂停和限幅。分别复用与精修原 CC0 刀锋录音、项目原创冰晶声音，来源与母版见 [`audio-production/basic`](../../audio-production/basic/README.md)。未借用商业游戏录音。

共用伤害、身份、资源与骨骼控制；人物攻击姿势、枪式／冰羽轨迹和声音分别制作。身体／攻击碰撞是实时球体、扫掠段和范围的近似，不是逐三角形精确物理。

## 真实测试与证据

- [`practice.json`](practice.json)：网页中逐阶段检查前摇不扣血、命中扣血、快速点击间隔、移动普攻、击毁／死亡一次、血量截断与重置。截图：[凌渊命中](lingyuan-basic-hit.png)、[月璃命中](yueli-basic-hit.png)、[木桩击毁](lingyuan-target-dead.png)。
- [`duel.json`](duel.json)：六技能由玩家／对手双方分别施放；所有伤害来源、目标与 tick 对应正确，中立训练目标在对战中不受伤害；两个人物均验证玩家胜利、AI 胜利、死亡停手与重置。骨骼 UUID 集合不相交，两个对手角色缓存有界。截图：[凌渊胜利](lingyuan-victory.png)、[月璃胜利](yueli-victory.png)、[AI 交战](lingyuan-ai-combat.png)、[落败](lingyuan-defeat.png)。
- [`controls.json`](controls.json)：844×390 横屏 CDP 双指移动＋普攻；单触一次只创建一次攻击；普攻前摇被技能取消后没有幽灵伤害；技能动作结束后接缓冲普攻，旧技能实例仍在；后台暂停／恢复；缺少单个普攻录音不阻断其他录音及扣血，重试成功。**是桌面模拟触控，不是真机。**
- [`regression/instances.json`](regression/instances.json)：原六技能各 1／3／5／10 次即时独立实例、音频事件、跑跳施法、十来源训练命中、时钟、锚点、池复用与回收通过。
- [`state.json`](state.json)：独立状态测试覆盖重复结算、自己／友方／未知目标、旧回合／旧人物代次、死亡一次、死后输入、持续伤害与减速到期、令牌过期后的去重清理。
- [`resources.json`](resources.json)：15 个角色／模型／特效源资产与基线逐字节一致；12 个普攻 Ogg 实际解码，均非空、文件各异且解码后峰值低于 0.98。网页音频共约 125 KB。电平测试不是专业听感验收。
- [`rendering.json`](rendering.json)：软件 WebGL2／WebGPU 实际显示双人物、两者均在镜头内，WebGPU 实际普攻和技能扣血；模式四轮切换后的渲染几何／纹理计数稳定；正常动作更新与调试寻帧下枪尖同步通过。基线与新训练场使用同一相机，木桩处于画面内。

## 复现与状态

`npm run build --prefix skill-src`；在 `dist` 启动现有静态服务器，再依次运行 `test_combat_state.mjs`、`test_combat_practice.py`、`test_combat_duel.py`、`test_combat_controls.py`、`test_combat_rendering.py`。原六技能回归使用 `LINGYUAN_REPORT_DIR=verification/combat/regression python3 tools/test_skill_instances.py`。图形任务顺序运行，`record_combat_play.py` 是独立的真实播放采集。
