## 真实缺口与修改位置

旧一技能龙身是近圆管、悬浮八面体鳞片和简单背刺，没有完整四肢与尾部结构，代码与 [`修复前侧视`](web/before-side.png) 一致。

- [`slash-dragon.ts`](../../skill-src/src/slash-dragon.ts)：为一技能单独制作闭合龙首／口腔／牙、分叉角、须、额颊鳞甲、肩腰起伏、285 片表面鳞甲、31 片腹甲、四肢钩爪和分叉尾鳍。按五种材质合并为九个几何批次，不增加辅助粒子或 Bloom。
- [`dragon.ts`](../../skill-src/src/dragon.ts)：保留原头部轨迹、枪尖锚点、时序、光带、冲击和粒子，只替换一技能未达标的关键实体结构；蓄力朝向与收尾朝向增加稳定处理。
- [`bind-star.ts`](../../skill-src/src/bind-star.ts)：显式使用原有 binding 配置，没有把一技能新造型直接复制到二技能。第三技能和月璃三个技能的造型、时间轴未改。
- [`main.ts`](../../skill-src/src/main.ts)：仅增加隐藏的龙体检查视角和数据入口，不新增用户设置、按钮或改变操作布局。
- [`Dragon_slash_master.blend`](../../characters/lingyuan/Dragon_slash_master.blend)、[`dragon-slash32.glb`](../../dist/quality/dragon-slash32.glb)：可编辑真实几何母稿与静态姿态 GLB。网页用同源程序化几何和实时曲线变形；GLB 本身没有骨骼动画，不冒充已制作的骨骼片段或数字雕刻高模。

这次采用封闭截面、曲线几何、表面鳞甲与 PBR 材质，没有宣称人工雕刻、重拓扑或高模细节烘焙已完成。原画依据为 `reference/skill01/04-dragon.jpg` 与原始技能板；参考图没有成为游戏里的平面龙贴图。

## 已验证的根因与失败处理

1. **短历史不能稳定构成完整龙身。** 首个样板的历史长度不足，补线方向随末段切线变化，120 Hz 检查曾触发约 2.38 m 的相邻样本位移断言。改用覆盖完整技能的历史、蓄力直线延展与按弧长取样；身体中心线约 3.8 m，避免头部停留时塌缩。最终密集样本最大步长约 0.101 m，检查范围仅为当前一技能轨迹。
2. **仅平行移动局部坐标仍会滚转。** 首个样板四肢朝上；在切线基底增加可用时的世界上方向投影约束，并检查正交性和朝上分量。没有把该限制机械推广到需要翻滚动作的其他龙。
3. **制作轴约定与运行轴约定不同。** 首次 Blender 检查镜头暴露了 Y-up 数据直接进入 Z-up 制作场景的问题；导入显式转换 `(x,y,z) → (x,-z,y)`，导出 glTF 转回。`asset.json` 验证最终位置集合与运行源匹配。错误方向的渲染没有作为最终证据保留。
4. **动态变形不能共享可变缓存。** 只读休息几何在 CPU 缓存，各实例分别克隆动态缓冲与材质；更新另一实例不改变已创建实例的顶点。释放仍走原生命周期，不释放只读模板。

自动检查与数据：[`geometry.json`](geometry.json)、[`asset.json`](asset.json)、[`binding-regression.json`](binding-regression.json)。二技能在五个轨迹时刻的顶点、法线、实例矩阵、透明度和头部朝向与基线完全一致。其他技能没有因复用而被同化。

## 实际证据与质量结论

- [`web/`](web/)：修复前后正面、侧面、背面、45°、俯视和龙首近景；[`comparison.json`](web/comparison.json) 记录实际相机与龙首位置，前后完全一致。
- 同一侧视画面的 Draw Calls **84 → 84**，绘制三角形 **85878 → 100754**；新增 14876 个绘制三角形用于结构。完整单龙静态模型为 27124 三角形。没有把更多面数本身作为美术通过证据。
- [`blender/`](blender/)：实际 Blender 母稿全身与龙首渲染；未使用概念图代替。
- [`instances.json`](instances.json)：一技能 1/3/5/10 次立即创建独立实例、独立音频事件，跑跳时第 11 次释放不覆盖旧实例，十次独立训练命中／命中音频及回收后复用通过。
- [`runtime/moving-cast.webm`](runtime/moving-cast.webm)：真实连续移动施法录像，没有 QA 快进或生成帧。软件环境中完整释放耗时约 **25.66 秒、56 渲染帧**，仍然缓慢；不能声称动态播放已达到流畅标准。录像无音轨，不证明物理音画延迟或专业听感。
- [`runtime/results.json`](runtime/results.json)：软件 WebGL2 与 WebGPU 均实际绘制十条龙。WebGL2 三轮十龙回收后均为 **96 个几何分配／11 个纹理**，活动时 184／11。计数稳定不等于总内存零泄漏、长期压力或安卓性能通过。
- TypeScript 构建、网格有限性／单位法线、帧正交性、中心线连续性、动态缓冲独立性与 GLB 往返验证通过。

**有限艺术采纳：** 鳞片已贴合实体，四肢、尾部和胸腰轮廓可从多角度辨认；不再只有管道轮廓。当前龙首仍有风格化简化感，鬃部、鳞片细腻程度和能量材质与原图仍有明显差距，未通过电影级／精品整体艺术验收，因此没有把新造型推广至另外两技能。

**仍未完成：** 两个人物的原画脸部神韵、完整发型／衣甲／武器精修、最终自然动作及衣发碰撞；另外两技能龙形独立精修。普攻、伤害、石柱与 1v1 按用户精品门槛未提前开发。**真机未验证**：安卓帧率、GPU／CPU 帧时间、长时运行、物理触控与音频延迟尚无数据。
