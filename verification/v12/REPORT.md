# V12 实际修复与未完成记录

## 访问权限

网站原先为 `custom` 私有访问，匿名请求返回 HTTP 401。用户明确选择公开后，将同一站点改为 `public`，匿名请求返回 HTTP 200。公开后持有链接者可访问站点及站点提供下载的模型资源。

## 共享龙首缺陷

实际检查发现 `makeDragonHead` 按材质合并几何时，某些部件带 UV、有些没有，`mergeGeometries` 因属性不匹配返回空值；原有 light/dark 两组未进入模型，包括牙齿、龙须及口腔部件。头骨网格面顺序导致外侧法线朝内。统一无贴图部件的几何属性并修正面方向后，五组材质均存在；正面法线 Y 从约 -0.965 改为 +0.965。`dragon-before.png` 和 `dragon-after.png` 是固定技能时间、相同视角、相同浏览器的软件 WebGL2 截图；`dragon-geometry.json` 记录结构检查。三个技能共用该龙首。造型与用户提供的精细神龙仍存在显著差距。

## 交互和可靠性

施法前持续按住移动方向不会在下一帧把技能立即取消；方向回到中性后再次输入才取消，并在取消／结束时将骨骼和角色旋转过渡至移动姿势。增加 1/2/3 技能快捷键。音频加载失败时出现全局提示，设置内显示声音状态；切到后台时暂停技能与声音，恢复后可手动继续。图形上下文丢失时显示重新加载入口。`interaction.json` 验证了按住方向释放、重新输入取消、姿态过渡和后台暂停；`audio-failure.json` 是拦截音频请求后的故障注入测试；上下文丢失也是合成事件，非真实 GPU 重置。

## 资源、动作和音频检查

`resource-audit.json` 与 GLB 检查确认三个 LOD 都包含同一骨架、角色与武器，以及 idle、walk、turn_left、turn_right 四个动作；每个 LOD 仅 1 / 16 材质带法线贴图。技能页加载 LOD1，三个技能为工程内动态几何；这些检查不代表造型与最新参考一致。

在临时 Blender 候选中制作了独立跑步循环并实际渲染 `run-candidate/` 的前后对照。候选脚部悬空、衣袍交叉明显，未通过验收，未写入正式 Blender 或 GLB。现有加速行走仍保留，但内部状态改称 `fast_walk`，不冒充独立跑步。模型现有三个面部形变均为脸型调整，不具备可验收的眨眼与表情。

九个音频源均可解码；`audio-levels.json` 是源文件电平扫描。`audio-mix.json` 是 48 kHz OfflineAudioContext 按当前参数混音的检测，三个技能峰值分别约 0.768、0.669、0.703，未检测到超过数字满幅的采样。音频事件记录增加 AudioContext 当前时间、计划时间与调度时的时间差；这些是计划值，并非物理扬声器实际触发时刻。没有对实机音画延迟或专业听感作判断。

## 测试及剩余项目

`regression/` 为真实浏览器软件 WebGL2 的三技能、移动、模拟横屏触控以及软件 WebGPU 的基础回归；`performance.json` 是单时刻软件渲染数据（采样约 3 FPS），不能代表手机性能，也没有本轮可比基线。三个 GLB 结构与现有资源引用检查通过，TypeScript 构建通过。没有连接安卓设备。
