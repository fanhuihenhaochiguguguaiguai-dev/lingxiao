# V3.1：凌渊头部样板与头发 LOD 根因修复

基线：`650edf1e1ea5d16493da7bf777a0f645ee42039d`（网站 V23）。本轮保留原场景、人物体系、六技能、操作布局和声音／画质设置。**V3.1 总任务尚未完成，头部候选没有通过艺术验收。**

## 正式修复：三档头发同时进入场景

现象：每个正式 `lingyuan-lod*.glb` 的活动场景都挂接 `Hair_Lod0/1/2`，Three.js 会一起加载与绘制；这与文件名所表达的单档 LOD 不一致。错误的场景挂接与缺少排他检查已证实。历史导出器只依赖选择状态，没有同时限定可见／可渲染对象；没有证据确定是哪个历史 Blender 操作首次引入错误。当前选择状态探针没有复现“隐藏对象残留选中”，不把该推测当成已确认根因。

- [`repair_lingyuan_lod_links.py`](../../tools/repair_lingyuan_lod_links.py) 只移除错误的活动场景连接；原二进制块、材质、蒙皮、形变及动画保持不变。未删除原始可编辑资源。
- [`export_refinement.py`](../../tools/export_refinement.py) 显式设置每个网格的选择／可见／渲染状态，只导出匹配档位，排除标有 `offline_only` 的离线母模。代表性 LOD1 重新导出后仅有 `Hair_Lod1`。
- [`validate_refinement.py`](../../tools/validate_refinement.py) 按实际活动场景检查唯一匹配头发、蒙皮、四个具名形变和原动作；不再把未挂接的网格定义计入活动三角形数。
- [`resource-validation.json`](resource-validation.json) 逐档比较基线与修复后资产，三档二进制、蒙皮与动画一致。活动模型总三角形为 LOD0 102970 / LOD1 67789 / LOD2 49925。

真实网页同一视角、姿态、光照、1100×700 画布的隔离对照：

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 活动头发档位 | 0、1、2 | 1 |
| 当前视角 Draw Calls | 59 | 53 |
| 当前视角绘制三角形 | 91094 | 60638 |

见 [`web/results.json`](web/results.json)、[`修复前`](web/before-face.png)、[`修复后`](web/repaired-face.png)。这些是桌面软件渲染计数，**不是 FPS 改善证据**。为保护既有数据，旧 GLB 的未使用定义和二进制仍保留，下载体积没有得到实质优化。之后从母稿干净导出可避免携带未选档位。

## 头部：真实制作候选，未替换正式人物

外观权威依据为 [`原始凌渊设计`](../../reference/1-1000069993.jpg)，[`五官细节图`](../../reference/detail/4-mmexport1793091788549.jpg) 作结构辅助，技能图只补充动作。原图透视与分辨率不统一，因此没有报告像素相似度或自动“神韵分数”。

本轮保留可用四边面笼、UV、60 骨骼和四个形变目标，分别调整下颌／颏部、颧颊面、鼻部、唇部及眼眶邻域；对基础网格与全部形变保持连续映射，眼球直径没有放大。它是程序化局部结构实验，**不冒充专业手工数字雕刻或已经还原原画**。

新增可编辑制作源 [`Lingyuan_head_candidate.blend`](../../characters/lingyuan/Lingyuan_head_candidate.blend) 与实时候选 [`lingyuan31-head.glb`](../../dist/quality/lingyuan31-head.glb)。母稿无损压缩保存，含低模笼和离线高模；不复制展示平台或建立新网站。

- 低模笼 4514 顶点，运行头部 UV 分裂后 4711 顶点；保留 `Blink`、下巴和脸颊形变。
- 离线高模基底 71861 顶点并带 1 层可编辑 Multires；在眼睑、鼻翼和唇部制作局部结构，不添加随机噪声冒充皮肤精度。
- 实际执行高模至低模的切线法线与 AO 烘焙：2048² 法线、1024² AO。图片嵌入 GLB，材质实际引用；高模没有进入运行场景。见 [`bake-report.json`](bake-report.json)、[`resource-validation.json`](resource-validation.json)。
- 新前发候选的 45° 角出现宽扁尖块，**已拒绝**，最终候选仍用原发型。仅保留两张失败证据于 [`rejected-groom/`](rejected-groom/)，默认脚本不启用该实验。

[`head/`](head/) 是相同姿态、固定正交相机／灯光的真实 Blender 正面、侧面、背面和 45° 对照；运行笼模式关闭细分，避免离线高模掩盖网页几何差异。当前安装的 Blender 无可用 OpenImageDenoise，图中存在采样噪声，没有用概念图或生成图片替换。

**艺术结论：** 当前脸部仍有通用底模感，眉眼、面颊与原画气质尚有明显差距；原发型的规整发束、发际线和发冠也仍未达标。新结构与烘焙可供继续编辑，不构成精品人物通过。正式入口保留原脸部，只采纳已验证的 LOD 修复；同一网站通过 `?sample=lingyuan31-head` 查看明确标注“艺术未验收”的候选。

## 实际验证与限制

- TypeScript 检查与构建通过。
- 三档正式资产结构／权重／形变／动作检查通过；候选正常贴图、AO、60 骨骼及离线高模排除检查通过。
- `test_lingyuan31_sample.py` 在实际页面检查软件 WebGL2／WebGPU 加载、唯一活动头发；候选凌渊三技能各 1/3/5/10 次独立释放、跑跳施法和到期回收，以及切至月璃再施法。
- 闭眼截图测试最初在设置 Blink 后重置了表情，证据无效；已调整顺序，并读取实际网格 Blink 权重验证闭眼值为 1。不是只检查按钮存在。
- [`video/head-and-first-skill.webm`](video/head-and-first-skill.webm) 是实际 Chromium 连续录像，没有模拟快进或生成帧。记录见 [`record.json`](video/record.json)：软件路径释放过程约 23.55 秒／56 渲染帧，**当前环境未呈现流畅实时播放**。录像不含音频，不能用它证明音画物理延迟或专业听感。
- 上一轮六技能全量并发、暂停恢复、命中事件、资源回收和双指模拟证据在 [`governance/`](../governance/)。本轮没有改写这些逻辑，继承其有效范围，未重复全部昂贵测试。
- **真机未验证**：安卓 60／30 FPS、触控延迟、GPU 帧时间、长时内存和物理音画延迟仍无真实设备数据。
