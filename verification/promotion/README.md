# 龙形方法推广与差异化运动修复

基线：`fd590c42e6d97f5e95cf8e053e50f6b70441ce84`，原网站 V25。本轮按用户授权推广已验证的结构／运动方法；保留人物、场景、操作、六技能时序、音频和命中机制。一技能已采纳的几何、法线及索引与基线完全一致，没有把四条龙换成同一模型。

| --- | --- | --- |

## 实际缺陷、根因和防回归

1. **苍穹龙身受光反常。** 原网格的遍历方向与环截面基底不一致，3.2 s 抽样最小外向法线点积约 **-0.948**。明确头到尾的统一计算约定，按该技能原有尾到头网格顺序取反向帧；修复后约 **+0.953**。不是增加曝光或 Bloom。
2. **冰龙俯冲挤成短柱。** 原 `path(u,t)` 对各段同时插值至几乎相同目标点，4.4 s 中心线仅 **0.894 米**。现在只有头部沿原俯冲目标运动，后续龙身沿历史路径按距离跟随；同一时刻约 **12.495 米**，不把法阵盘龙或升腾螺旋强制改成这一轨迹。
3. **冰龙回旋转头突跳。** 近竖直方向直接用世界朝上重建朝向，叠加短段方向采样和原路折返。改为从尾向头传递身体基底、使用该冰龙颈长对应的采样范围并给返程保留侧向弧度。120 Hz 几何采样的单步最大头部旋转：基准种子 **2.353 → 0.125 弧度**；十个实例种子均小于 0.20 弧度。这是几何连续性检查，不是设备帧率成绩或完整动态审美验收。
4. **冰龙左右爪方向不协调。** 原做法把同一侧腿旋转 180° 当作另一侧，连前后朝向也反转。改为在几何中制作镜像配对，再按相同前向放置两组；三种新适配肢体分别有不同厚度、伸展和趾爪。
5. **子节点索引剔除会误删新增部件。** 原缚星阵用 `children.slice(5)` 移除一技能装饰，新增腿部也会落入该范围。改为由效果明确隐藏自己的斩击装饰，保留所有权并继续走原资源回收机制。
6. **改主角形状未移动分叉根点。** 首次候选在 Blender 近景暴露悬空角叉，未采纳；分叉起点现直接引用主角路径中的锚点。今后曲线改形须同时更新附属结构，不沿用孤立旧坐标。
7. **混合索引状态不能直接合并。** 新冰羽几何与截面网格合并前统一索引与所需属性；自动检查要求五种材质几何组齐全，避免缺件或空几何被当成加载成功。
8. **新龙首不能沿用旧颈部尺寸。** 最后近景发现候选冰龙旧颈圈遮住面部，失败图见 `rejected/ice-neck-collar.png`。按自己的头部体积将颈部起点后移 0.34 米、头端截面收至约 0.16 米，并按椭圆截面修正鳞片贴合；头部方向使用独立的颈部历史支撑，避免接点变化重新引入转头突跳。最终冰龙另作定向回归，不复测未变化的其他模型。

代码位置：[`dragon-frames.ts`](../../skill-src/src/dragon-frames.ts)（基底／历史弧长）、[`dragon-geometry.ts`](../../skill-src/src/dragon-geometry.ts)（复用闭合几何）、[`dragon-details.ts`](../../skill-src/src/dragon-details.ts)（分别定义甲片和成对肢体）、[`dragon-head.ts`](../../skill-src/src/dragon-head.ts) 与 [`lunar-dragon-head.ts`](../../skill-src/src/lunar-dragon-head.ts)（独立龙首）、原有 `dragon.ts` / `bind-star.ts` / `star-vortex.ts` / `ice-dragon.ts`（各自演出）。输入、技能注册、音频和训练命中没有另建控制器。

## 验收边界

- TypeScript 和正式构建通过。`before-geometry.json` / `after-geometry.json`、`checks.json` 检查法线、中心线、头部朝向、不同种子、独立状态及一技能原始几何哈希。
- `instances.json`：六技能各 1/3/5/10 次即时释放、独立音频事件、跑跳施法、独立训练命中、时钟和池复用通过；当前只是训练判定，不是正式对战伤害。
- `runtime/lifecycle.json` 与颈部最终定向复验 `runtime/lunar-final.json`：软件 WebGL2／WebGPU 实际绘制三种龙各十实例，WebGL2 各三轮回收计数稳定；不等于总内存零泄漏或长时测试通过。
- [`runtime/lunar-continuous.webm`](runtime/lunar-continuous.webm)：实际连续完整大招，无模拟快进或生成帧。软件环境约 **117.05 秒／143 渲染帧**，仍不流畅；录像无音轨，音频事件测试不能代替物理音画延迟或专业听感。
- **真机未验证。** 没有安卓硬件帧率、触控／音频延迟或长时内存数据。

本轮采纳的是连接、朝向、连续龙身及独立造型的有限改善。龙首仍有简化感，原画级雕刻、鳞甲精细度、材质、部分局部弯曲与穿插仍需艺术检查；没有宣称所有不自然现象或电影级品质全部通过。人物五官、衣发物理及后续战斗玩法本轮没有扩大开发。

只复用数学、资源约定和验证方法；各龙的长度、截面、角叉、鳞甲、爪形、滚转策略和路径由各自艺术设计决定。以后新增龙形应先确认来源与运动约束，禁止把此次三种配置当成所有人物的默认外观。
