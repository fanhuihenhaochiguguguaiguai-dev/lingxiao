# 凌渊角色工作室 V11 增量记录

## 根因和改动

原人物详情页可以移动，技能页却使用固定原点和独立相机，因此移动后无法在原位置施法。现在在原技能页复用既有模型、骨架和三个特效，将角色和技能放在共同的局部场景组中；技能以当前角色位置与朝向为起点。一技能结束前限制突进位置，避免移动恢复时越界跳回。场地半径由 4.1 扩至 17，可行走半径为 9.5，新增低对比度的地面分格线。

加入键盘、方向键与触屏虚拟摇杆；移动带加减速和朝向插值，镜头默认平滑跟随人物，技能释放时调整观察距离，大招抬高观察中心。原视角、自由环绕缩放、跟随模式、画质、图层、暂停、逐帧、慢动作、循环和时间轴集中到可折叠面板。纯净模式可退出，角色详情页和下载保留。

三个技能按时间轴组合播放不同 CC0 录音及游戏音效层，使用 AudioContext 时钟调度、音量与静音、立体声声像及压缩器；浏览器交互时解锁，暂停、拖动、切换或技能中断时停止已排队的声音。各文件许可及原始来源见 `../../dist/skill/audio/ATTRIBUTION.md`。这些是授权素材混音，不是专门录制的电影级龙吟。

## 验证

- `results.json`、`initial.png`、`skill2-moved.png`、`ultimate.png`、`landscape.png`：桌面软件 WebGL2 中真实移动、跟拍、移动后释放三个技能、音频解码和音频输出非零信号、暂停取消声音、调速、循环开关、技能图层、逐帧、画质与纯净模式，以及模拟 844×390 横屏触控摇杆。非 Android 真机。
- `webgpu.json` 与 `webgpu-ultimate.png`：软件 WebGPU 下角色移动、大招与音频调度检查。
- `boundary.json` 和 `boundary-ultimate.png`：键盘移动到边缘后，一技能人物位置未超过 9.5 的半径；大招地面效果半径按 3.5 计算落在半径 17 的平台内。截图是实际软件渲染结果，不代表所有相机角度都不裁切。
- `npm run build --prefix skill-src` 通过 TypeScript 检查与构建。自动检查没有进行扬声器听感评审或精确音画延迟测量；低帧率、加载未完成或移动端音频策略可能改变首次声音时机。

## 未完成

人物面部、皮肤、头发和服装没有本轮专项艺术精修；没有可靠的眨眼、眼球控制、脸部表情、足部 IK 或布料碰撞。移动的“跑步”是加速已有行走片段，尚不能宣称自然跑步或无滑步。三技能和龙形仍明显低于用户参考，未经美术验收；自动缩放并非完整电影级运镜，缺少场景障碍物碰撞和复杂遮挡处理。没有真实安卓设备，手机 FPS、帧时间、内存、扬声器听感和兼容性均未验证。本轮未打包 APK。
