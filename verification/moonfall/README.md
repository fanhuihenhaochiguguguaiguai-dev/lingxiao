# 月璃原画比例修整与月陨天霜：真实验收记录

本轮继承 V21（`c4bee71638f92cabbbff55cf5bda10e4fee597db`）。当前网页、Blender 和 GLB 是一份正式工作稿；未通过原画神韵／电影级艺术验收。以下将已检查的技术行为与仍未达标的美术分开记录。

## 人物实际修改

- 以原始银白发 board-04／board-01 为外观依据，技能图仅补充技能姿态。调整眼眶与眼部构件的对应比例、下颌、下巴、鼻翼鼻尖和唇部局部体积，同时变换 Blink 的对应坐标，保留原 UV、骨骼与已应用的衣层厚度。
- 3971 个 Blender 基础顶点有位移；导出后含 UV 分裂的身体网格中 4128 个顶点发生位移，最大约 9.34 mm。身体 POSITION 数量 14517 不变，36 根骨骼保留。数字只是几何变更证据，不是精度或相似度评分。
- 替换尚未合格的僵硬前发条为渐细曲面发束和细束；保留现有后发。新增贴合现有衣层的象牙色前胸衣片与细金饰；部分球状花瓣改为有厚度的尖瓣和金边。未完成完整发型、裙装或鞋靴重建。
- `characters/qingli/Yueli_working.blend` 为可编辑母稿，`Yueli_working.glb` 与 `dist/yueli-study.glb` 字节一致，哈希见 `character/export-geometry.json`。模型从 9,348,216 增至 10,097,480 字节（约 +8.0%），未作移动端性能通过结论。月影寒潮的派生月影模型同步重新提取，资源 URL 使用相同模型修订号。
- `character/before-*.png` 与 `candidate-*.png` 是相同正交相机／灯光／姿态的真实 Blender 渲染。`reference-before-after.png` 同时列出原图 124×132 像素特写；原图是透视图且分辨率有限，不将两者像素差当几何误差。`tools/render_yueli_reference.py` 固定从 V21 Git 提取旧母稿，避免把当前母稿误作升级前基线。

## 第三技能实际实现

`skill-src/src/moonfall.ts` 与 `ice-dragon.ts` 接入原有 `SkillInstances`、人物切换、移动、镜头和音频系统；月璃现有第三按钮为「天霜」，键盘 3 可释放。保留凌渊三技能及月璃前两技能。

| 阶段（测试配置） | 实际结构及行为 |
| --- | --- |
| 0–1 s 九重凝月 | 九组独立变换的环轨／符文、月球逐渐形成 |
| 1–2.9 s 冰龙降临 | 管面龙躯连续形变、立体角须牙鬃、160 片鳞甲、28 背鳍、四肢与爪；沿空间曲线盘旋 |
| 2.9–4.4 s 月陨天霜 | 具有凹坑几何和原创表面纹理的球形月轮下降；龙首俯冲，40 冰晶生长、27 冰莲花瓣、三层冲击环 |
| 4.4–9.4 s 九界归墟 | 龙躯重新展开、环轨独立旋转、冰晶／碎片／近似霜雾持续；半径 4.5 的训练范围判定 |
| 9.4–11.4 s 自然消散 | 鳞片离体、月轮与法阵渐隐、霜雾和碎片衰减；实例及尾音结束后回收 |

复用现有共有龙首拓扑生成器和几何构件；静态拓扑共享，可变龙躯缓冲、材质、流动时钟、ID、出生变换、命中集合和音频均为实例独立。并发时减少辅助碎片密度，不删技能实例；实例种子也改变盘旋相位，十条龙不只占据完全相同路径位置。人物新增抬臂凝月姿势，与原有下半身接触求解、奔跑、跳跃混合；不是新制作的完整离线动作片段。

时长与命中数值是当前展示／训练配置，未擅自定义正式游戏伤害或平衡。范围内训练目标分别记录各实例的持续命中和减速贡献，不是已接入完整对战伤害系统。

## 本轮确认并修复的原因

1. 仅写 Blender shape key 坐标时，最初候选的导出基础网格未发生预期变化。同步基础网格与形变键，并检查实际 GLB POSITION，而不只检查修改脚本存在。
2. 发根射线未命中头皮时使用固定前方坐标，造成侧视悬浮发笼。未命中时保留连续发束路径；只在确实命中表面时贴合。
3. 衣片按面中心选取形成锯齿接缝；改为精确平面裁切并补 1.5 mm 边厚。冰晶生成初期只压缩高度，产生黑色扁片。三轴共同生长并按阶段控制可见性；冲击环半径与淡出分开，避免退缩。
4. 独立实例必须拥有独立材质和动态缓冲，但不应重复生成相同龙首。缓存不可变龙首拓扑，回收只释放实例资源；重生检查避免错误释放共享几何。
5. 旧训练减速只有单一写入槽。改为每目标按实例维护贡献与到期时刻，避免新实例覆盖旧来源。

## 音频

新增第三技能八类声音：凝聚、月轮、龙吟、结晶、爆发、领域、命中、消散，每类三种轮换变体，共 24 个原创 Ogg；保存八份 48 kHz 双声道 float32 WAV 母版。制作脚本使用噪声、非整数共振、颗粒碎裂、共振峰咆哮与立体反射，不使用未授权商业游戏录音。

共用音频预解码、按实例空间位置触发、轻微音高变化、动态混音与限幅。整个两人月系音频库现为 66 个 Ogg、22 个母版。`audio.json` 的生产混音链离线检测中，单次第三技能峰值 0.384、十次峰值 0.305，均无削波；十次共调度 140 个分层／命中声源。音色统计与电平检测不能代替专业听感、实际音视频延迟或手机扬声器验收。
