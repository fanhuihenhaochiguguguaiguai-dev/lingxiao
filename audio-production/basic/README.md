# 普攻声音母版

四种独立短音色：长枪释放／命中、月璃冰羽释放／命中，各三个变体。母版保留变体 0 的 48 kHz stereo float WAV，网页使用全部十二个 Ogg。

生成器：`tools/build_basic_audio.py`。源为原项目已使用的 CC0 刀锋／石材录音（[完整来源](../../dist/skill/audio/ATTRIBUTION.md)）和项目原创的月华霜羽颗粒／玻璃共振素材。进行短段混合、音高／瞬态和尾部处理，没有引入商业游戏录音。逐文件来源在 `dist/skill/audio/basic/manifest.json`。

音频解码、电平、事件与变体测试不能替代专业试听或真机延迟测量。
