# 早期人物重建输入

`poxiao.glb` 是早期制作凌渊工作稿时使用的工作区 `/workspace/yaojing/assets/heroes_rebuilt/poxiao.glb` 重建候选副本，不是人物原画对应的原始三维模型。SHA-256：`571ffc0813d49b6eb42f14eef83d82bd0d79d38e902cad07a4a08d889031134c`。

`tools/build_character.py` 默认使用本文件；仅凭重运行早期脚本不能复现之后所有精修，也不能代表人物已经通过艺术验收。当前可编辑母稿、导出的模型和历次修改仍以仓库相应文件及 Git 历史为准。
