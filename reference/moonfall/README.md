# 月陨天霜参考来源

本目录保留本轮上传 ZIP 的两张 1536×1024 原图。`manifest.json` 记录原图及压缩包 SHA-256；`crop-index.json` 记录 34 张主要阶段、构件与场景范围裁图的原始像素坐标、尺寸和摘要。裁图与原图相应区域逐像素一致，未进行生成式补画或超分推测；不宣称已拆出整板的每一个微小画面。

这些图片仅用于月轮、冰龙、冰莲、法阵、冰晶、施法阶段的设计参考。图片中的脸和衣装不替代人物造型标准。月璃外观仍以 `../qingli/originals/board-04.jpg` 为主、`board-01.jpg` 为结构补充；黑发 board-03 独立保留。

技能使用真实程序化球体、管面、鳞片、龙首、角须、爪、花瓣、符文与冰晶几何，未将设定图作为整张特效贴片。运行时月球色彩／法线贴图由 `tools/build_lunar_surface.py` 原创生成，用于有厚度球体的表面材质。
