# 清璃参考图拆解

第 2 张银白发「清璃」为用户确认的主设计，第 1、4 张是辅助参考；第 3 张黑发造型为独立变体，仅作对比，不混入主设计。`originals/` 保留全部原始 JPEG，`crops/` 保存原始像素 PNG，`upscaled/` 是 Lanczos 2 或 4 倍插值，未使用生成式修复，不会还原原图缺失细节。

`index.csv`、`index.json` 记录每张的类别、原图、坐标、比例和校验值。主设计的全身、飘带等在原图中跨视图重叠，裁切标记 `needs_review`；未进行前景分离，不能声称这些区域已完全独立，也不能保证所有细节边界均自动验证。模糊纹样需人工确认。

拆图使用针对四张图片人工制定的区域坐标及批处理，并非已经验证的通用自动识别算法。当前共有 276 个区域；75 项标记待复核，其中 60 项属于不采用的黑发变体，其余是全身视图等源图相互重叠的区域。部分相邻画面在原图中交叉，尚无法保证完全分离；所有标签和边界仍需人工复核。
